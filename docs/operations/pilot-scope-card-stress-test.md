## HYPOTHESIS TO TEST — Account findings

### OSP-001 — SuperVive / Rosa Es Rojo

- **HYPOTHESIS TO TEST — Fit:** Offer 2 program-launch/compliance only if a current nonclinical implementation gap exists.
- **Why:** The app/referral initiative and capacity-funding evidence could support a bounded implementation calendar, partner map, reporting framework, or evidence-file system.
- **Missing qualification facts:** current award period; remaining/uncommitted technical-assistance funds; implementation phase; responsible buyer; actual system gap; procurement method; data access; conflict review.
- **Hard boundary:** no referral judgment, counseling, clinical workflow authority, PHI-heavy work, or unsupported outcome claim. Licensed clinical authority remains external.
- **Delivery burden:** medium-high unless a coordinator owns recurring partner/reporting loops.
- **Proof/partner gate:** nonclinical implementation sample, document-control method, data/BAA controls, coordinator, and licensed reviewer wherever clinical judgment approaches scope.
- **Data correction:** keep one program-launch hypothesis; remove continuation-funding language until a distinct funding-pipeline signal exists.
